Port evidence key

a capture is evidence, not a scan
SERVING — the host answered: TCP SYN/ACK came back from it, or the conversation ran both ways.
RESPONDING — UDP: the host sent traffic back out of that port to a peer that addressed it.
REFUSED — it answered with RST, or an ICMP port unreachable. Host is up, that port is closed.
OBSERVED — addressed only, never answered in this capture. Suspected, not proven.

Where the capture starts mid-conversation there is no handshake to prove which end is the server, so the role is inferred from port numbers and the evidence column says role inferred. Ephemeral source ports are ruled out first — FL-net (55000), DNP3 (20000) and EtherNet/IP I/O (2222) all sit inside the range operating systems hand out to clients.
